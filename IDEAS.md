## QR-код генератор

### Что делает

Генерирует QR-код из произвольного текста или ссылки и возвращает PNG-изображение.

### API

| Эндпоинт | Метод | Описание |
|---|---|---|
| `/api/v0/qr` | `GET` | PNG-изображение QR-кода |

### Что сервер принимает (query-параметры)

Все параметры передаются в URL как query string.

| Параметр | Тип | Обязательный | По умолчанию | Описание |
|---|---|---|---|---|
| `text` | string | да | — | Строка для кодирования в QR. Может быть URL, WiFi-конфигом, plain text. Макс. ~2000 символов. |
| `size` | integer | нет | `300` | Ширина и высота результирующего PNG в пикселях. Минимум 100, максимум 2000. |
| `fg` | hex string | нет | `000000` | Цвет модулей (точек) QR-кода в hex без `#`. Пример: `FF0000` — красный. |
| `bg` | hex string | нет | `FFFFFF` | Цвет фона QR-кода в hex без `#`. Пример: `FFFFFF` — белый. |

### Что сервер возвращает

**Успех (200 OK):**

```
Content-Type: image/png
Content-Length: <размер в байтах>
```

Тело ответа — бинарные данные PNG-изображения. Без JSON-обёртки — изображение отдаётся напрямую.

Браузер отобразит картинку сразу при открытии URL.

**Ошибка (400 Bad Request):**

Если `text` не передан или пустой, или `size` вне допустимого диапазона:

```json
{
  "error": "Parameter 'text' is required"
}
```

```json
{
  "error": "Parameter 'size' must be between 100 and 2000"
}
```

### Примеры запросов и ответов

---

**Запрос:** простой текст

```
GET /api/v0/qr?text=Hello%20World
```

**Ответ:** 200 OK, `image/png` — QR-код размером 300×300 px, чёрный на белом.

---

**Запрос:** ссылка с кастомизацией

```
GET /api/v0/qr?text=https://example.com&size=500&fg=FF0000&bg=FFFF00
```

**Ответ:** 200 OK, `image/png` — QR-код 500×500 px, красные модули на жёлтом фоне.

---

**Запрос:** WiFi-конфиг

```
GET /api/v0/qr?text=WIFI:S:MyNetwork;T:WPA;P:secret123;;
```

**Ответ:** 200 OK, `image/png` — QR для подключения к WiFi.

---

**Запрос:** без `text`

```
GET /api/v0/qr
```

**Ответ:** 400 Bad Request

```json
{
  "error": "Parameter 'text' is required"
}
```

---

### Пример использования на фронтенде

```html
<img src="/api/v0/qr?text=https://example.com&size=300" alt="QR Code" />
```

### Архитектура

- Новая зависимость: `com.google.zxing:core` + `com.google.zxing:javase`
- **Только сервис `QrCodeService`** — никаких репозиториев или JSON-хранилища не нужно
- Сервис: ZXing `BitMatrix` → `BufferedImage` → `byte[]`
- HTTP-хендлер: парсит query-параметры, вызывает сервис, отдаёт `image/png`
- Фронтенд: новая HTML-страница `qr.html` + кнопка на главной
